# Frontend-Mentor-Contact-Form-

## Project Overview
This repository contains a **single-page design** for the Frontend Mentor “Contact Form” challenge.  
The goal of this project was to design a clean and user-friendly contact form that is visually appealing and easy to use.

## Design Highlights
- **Layout:** Simple, intuitive one-page design focused on the contact form.  
- **Typography:** Carefully chosen fonts for readability and clarity.  
- **Colors:** Harmonious color palette to enhance visual appeal.  
- **Visuals:** Custom design elements and spacing for a modern look.

## Tools Used
- Figma (used for designing the contact form layout)  
- Image editing tools for exporting the design file
